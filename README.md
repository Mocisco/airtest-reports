# Airtest 游戏画质自动化测试平台

基于 Airtest 的游戏画质截图自动化测试框架，支持多设备并行执行、Web 可视化管理和截图对比报告。

## 功能特性

- **多设备并行测试** - 支持同时连接多台 Android 设备执行自动化任务
- **画质模式全覆盖** - 自动切换极致/均衡/省电三种画质模式进行截图
- **Web 可视化界面** - Flask + SocketIO 实现的实时监控和控制面板
- **截图质量检测** - 内置图像质量分析，自动识别黑屏、色偏等异常截图
- **UI 语义标注系统** - 支持前端标注 UI 元素并驱动自动化执行
- **云真机集成** - 支持连接云端设备池，自动占用和释放
- **自动归档清理** - 超过保留期限的截图自动打包归档

## 快速开始

### 环境要求

- Python 3.8+
- Android SDK (adb)
- Airtest
- PaddleOCR (可选，用于文字识别)

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

服务启动后访问:
- 本机: http://localhost:5000
- 局域网: http://<本机IP>:5000

## 配置说明

### 设备配置

在 `data/device_caps.json` 中配置各设备的画质档位:

```json
{
  "Mate_60_Pro": "极致",
  "vivo_X100": "极致",
  "nova_13": "均衡"
}
```

### 坐标配置

游戏内各元素的相对坐标配置在 `data/game_coords.json` 中:

```json
{
  "default": {
    "出城": [0.064, 0.896],
    "前往征战": [0.505, 0.794],
    "画质设置": [0.07, 0.256]
  }
}
```

### OCR 配置

通过环境变量控制 OCR 级别:

```bash
# 0 = 关闭 OCR，仅使用模板匹配 (默认，推荐)
# 1 = 仅在关键场景启用 OCR
# 2 = 全量 OCR
export AIRTEST_OCR_LEVEL=0
```

## 核心模块

### AirtestService (airtest_service.py)

自动化执行核心类，负责:

- **账号池管理** - 线程安全的账号分配和回收
- **设备连接** - ADB 多设备并行连接
- **流程控制** - 新包初始化、截图任务执行
- **图像分析** - 截图质量检测和异常标记
- **UI 探索** - 自动探索 UI 状态机

主要流程:

1. **流程A - 新包初始化**: 首次安装后的登录配置
2. **流程B - 截图任务**: 登录后执行画质截图
3. **流程C - 装包任务**: APK 安装自动化

### PlaywrightCloud (playwright_cloud.py)

云真机自动化控制，负责:

- **设备占用** - 从收藏列表自动占用可用设备
- **ADB 隧道** - 建立云端设备与本地的连接
- **设备释放** - 任务完成后自动释放设备
- **缓存恢复** - 服务重启后的释放兜底

### ReportManager (app.py)

报告管理模块:

- 截图文件夹扫描和报告生成
- 多设备、多画质模式分组
- 历史报告归档和对比

## Web 接口

### 设备管理

| 接口 | 方法 | 说明 |
|------|------|------|
| `/get_devices` | GET | 获取已连接设备列表 |
| `/connect` | POST | 批量连接设备 |
| `/disconnect` | POST | 断开设备连接 |

### 任务控制

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/run_test` | POST | 启动截图任务 |
| `/api/run_login_only` | POST | 仅执行登录流程 |
| `/api/stop_test` | POST | 停止运行中任务 |
| `/api/logs` | GET | 获取任务日志 |

| 接口 | 方法 | 说明 |
|------|------|------|
| `/scan` | POST | 扫描新截图生成报告 |

| `/compare_page` | GET | 截图对比页面 |
| `/delete_report/<rid>` | POST | 删除报告 |

### 云真机

| 接口 | 方法 | 说明 |

## 自动化流程

### 截图任务流程

```
1. 启动游戏 APP
2. 等待登录界面 → 输入账号密码
3. 选择服务器 → 进入游戏
4. 遍历画质模式:
   - 打开画质设置
   - 切换画质档位
   - 截图保存
5. 关闭游戏 → 释放账号
```

### UI 状态机

系统支持 UI 状态自动探索:

1. 截图当前界面
2. 提取 UI 候选图标
3. 点击候选图标
4. 检测界面变化
5. 记录状态转换
6. 生成状态图谱

## 图像质量检测

自动检测以下异常:

- **黑屏** - mean_luma < 18
- **大面积黑块** - black_ratio > 0.28
- **色偏** - cast_ratio > 1.7
- **噪点/花屏** - 特定纹理会触发

异常截图会标记并复制到 `_bad/` 目录。

## 云真机集成

连接云真机平台:

1. 在 Edge 中打开云真机管理页面
2. 启动 Edge CDP 模式 (端口 9222)
3. 使用 Web 接口自动占用设备
4. 任务完成后自动释放

## 注意事项

1. **账号安全**: 生产环境请使用临时测试账号
2. **设备数量**: 根据机器性能合理配置并发数
3. **OCR 级别**: 建议保持默认关闭以获得最佳性能
4. **归档策略**: 定期备份重要截图到归档
